# 行事カレンダー(GitHub Pages 用)

町内会・サークル・学校などの行事予定を、スマホのブラウザで見られるカレンダーです。
ホーム画面に追加すると、アプリのように開けます。

## 1. 公開する

1. GitHubで新しいリポジトリを作ります(例: `gyoji-calendar`)。無料プランでGitHub Pagesを使うには **Public** にします。
2. このフォルダの中身(`index.html`、`events.json`、`sw.js`、`manifest.webmanifest`、`icon-192.png`、`icon-512.png`)を、すべてリポジトリの一番上に置きます。リポジトリの「Add file」→「Upload files」からアップロードできます。
3. リポジトリの「Settings」→「Pages」で、「Deploy from a branch」、ブランチは `main`、フォルダは `/ (root)` を選んで保存します。
4. 1〜2分後、`https://ユーザー名.github.io/リポジトリ名/` で開けるようになります。このURLをメンバーに共有します。

> Publicのリポジトリは、予定のデータ(`events.json`)もだれでも見られます。公開してよい予定だけを入れてください。

## 2. 予定を更新する(管理者)

### 方法A: GitHubの画面で直接編集する(かんたん)
リポジトリの `events.json` を開き、鉛筆のアイコンで編集して「Commit changes」を押します。形式は次のとおりです。

```json
{
 "d": "2026-11-15",        // 日付(年-月-日)
 "t": "防災訓練",           // タイトル
 "time": "9:00〜11:00",     // 時間(なければ空の "")
 "place": "小学校 校庭",     // 場所(なければ "")
 "cat": "event",           // event=行事 / meet=会議 / duty=当番・募集
 "note": "消火器の体験あり"  // メモ(なければ "")
}
```
(上の `//` 以降は説明用です。実際のファイルには書かないでください。)

### 方法B: ページの「管理者モード」で編集する
1. GitHubの「Settings」→「Developer settings」→「Personal access tokens」→「Fine-grained tokens」→「Generate new token」を開きます。
2. 「Repository access」で「Only select repositories」を選び、このリポジトリだけを選びます。
3. 「Permissions」→「Repository permissions」→「Contents」を **Read and write** にします。
4. 作ったトークンをコピーします。画面を閉じると二度と見られません。
5. 公開ページの「管理者モードに入る」を押し、トークンを貼り付けます。
6. 「＋予定を追加」や各予定の「編集」で変更すると、`events.json` に自動で保存されます。反映には1〜2分かかります。

- トークンは、入力したスマホ・パソコンのブラウザにだけ保存されます。ほかの人に渡さないでください。
- 管理者を増やすときは、その人をリポジトリの「Collaborators」に追加し、本人にトークンを作ってもらいます。
- 同時に2人が編集すると、あとから保存した人の内容で上書きされることがあります。

## 3. スマホで使う

- iPhone: Safariで開き、共有ボタンから「ホーム画面に追加」を選びます。
- Android: Chromeで開き、メニューから「ホーム画面に追加」または「アプリをインストール」を選びます。
- 電波がないときは、前回表示した内容が出ます。
- 各予定の「カレンダーに追加」を押すと、Googleカレンダーに登録できます。通知はカレンダーアプリ側の設定で届きます。
